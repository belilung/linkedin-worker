# LinkedIn Worker

**English** · [Русский](README.ru.md)

LinkedIn cold-outreach automation: scrapes search results, comments on posts, sends Connect requests and DMs. Messages and comments are generated by Claude AI in your voice and tailored to each lead's context.

## Quick start

1. Unpack the archive, open a terminal in the folder
2. **macOS/Linux:** `./setup.sh` &nbsp;&nbsp; **Windows:** `setup.bat`
3. Open `.env` and paste your `ANTHROPIC_API_KEY` ([get one](https://console.anthropic.com/settings/keys))
4. Open `config.yaml` and tweak to your needs (inline comments)
5. Log in: `linkedin-worker login`
6. Run: `linkedin-worker connect --dry-run` (preview) → `linkedin-worker connect`

Full guide: **[INSTALL.md](INSTALL.md)**

## Three commands

- **`run`** — DM existing 1st-degree connections
- **`connect`** — comment on other people's posts + send Connect requests
- **`dm-recent`** — DM people who recently accepted your Connect

## Requirements

- Python 3.11+
- Anthropic API key (≥ $5 balance; ~$0.60 per 200 messages)
- 5 minutes to set up

## Safety

- Stay under 20–40 Connects and 50–100 comments per day
- Don't drop delays in `config.yaml` below 3 seconds
- Always start with `--dry-run`
- Cookies and DB live in `data/` — never share that folder
